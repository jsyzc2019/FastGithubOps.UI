# FastGithubOps.UI v2.6.16

## 修复

- 托盘「重新选优 IP」在社区候选通过不足三个时补测内置地址，只把通过探测的候选写入配置。连接状态会标明固定配置和动态回退。
- Git 请求失败日志增加转发错误、响应是否已开始和请求取消状态，便于判断故障发生在等待响应头还是正文传输阶段。
- WPF 遇到内存耗尽时采用默认异常退出路径，并在 `ui-error.log` 记录进程与终止状态。
- 将 `Yarp.ReverseProxy` 更新到 `1.1.2`，修复 `CVE-2023-33141`。 [安全公告](https://github.com/advisories/GHSA-jrjw-qgr2-wfcg)
- Windows 单文件发布包保留应用单独启动的 `dnscrypt-proxy.exe` 和它的配置。发布脚本在公开 Release 前核对两个资产的大小和 SHA-256。

## 下载与校验

1. 下载 `fastgithub-win-x64.zip` 和 `fastgithub-win-x64.sha256`，将 ZIP 完整解压到同一目录。
2. 用 `Get-FileHash -Algorithm SHA256 -LiteralPath .\fastgithub.exe,.\FastGithub.UI.exe` 计算两个程序的 SHA-256，并与清单逐项核对。
3. 以管理员身份运行 `FastGithub.UI.exe`，以便使用 WinDivert 透明拦截。
