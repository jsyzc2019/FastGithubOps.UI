# FastGithubOps.UI v2.6.18

## 管理员登录自启

- 修复以管理员身份启用自启时，受保护的自定义安装目录因 NTFS 卷根自身权限而被误拒绝的问题。卷根仍会检查删除子项和修改权限等授权，普通父目录和安装文件必须通过完整的权限检查。
- 使用 Windows 直接挂载的本地固定盘符作为任务路径。目录映射盘符、目录联接和符号链接会被拦截。
- 设置页列出安装目录要求，失败时指出被拒绝的路径和具体条件。

如需安装到 D 盘，可在根目录下准备独立的受保护子目录。若 `D:\FsTools` 等父目录仍允许普通账户修改，程序会提示使用受保护的安装位置。 [自定义安装目录](https://github.com/FluxForceDynamics/FastGithubOps.UI/blob/v2.6.18/README.md#使用自定义安装目录)

## 下载与校验

1. 从本版 Release 下载 `fastgithub-win-x64.zip` 和 `fastgithub-win-x64.sha256`，完整解压 ZIP。
2. 运行 `Get-FileHash -Algorithm SHA256 -LiteralPath .\fastgithub.exe,.\FastGithub.UI.exe`，对照清单逐项核对。
3. 使用要自动启动托盘的管理员账户打开 `FastGithub.UI.exe`，在托盘「设置」中启用或更新自启任务。
