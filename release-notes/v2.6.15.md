# FastGithubOps.UI v2.6.15

本 fork（FluxForceDynamics/FastGithubOps.UI）相对上游 v2.6.14 的首次独立发版，聚焦两件事：把 `git clone` 链路的**成功率/稳定性**做起来，以及「非管理员运行」的**易用性**。全部改动不涉及突破跨境链路物理带宽，上游已实现的 IP 健康度反馈、成功 IP 记忆、候选池扩充等能力保持不变。

## P0：git clone 慢/失败的根治

实测两层根因：一是原 IP 探测只做 TCP 握手（「TCP/网页通 ≠ git 协议通」），导致建连快但 git 协议不通的官方 IP 被排到候选首位；二是 `github.com.Timeout=25s` 是建连+传输的整体预算，大 pack 在跨境链路上被 `CancellationToken` 砍断。

- **git 智能协议独立宽松超时**：`TelemetryPolicy` 对 `info/refs` / `git-upload-pack` / `git-receive-pack` 路径放宽到 10 分钟；普通请求仍按域名默认预算快速失败
- **固定 IP 多候选列表**：`DomainConfig` 新增 `IPAddresses[]`（兼容旧单 `IPAddress`，列表优先），建连按配置顺序逐一回退；三条固定地址失败后仍给动态池留一次机会
- **托盘一键选优**：「重新选优IP」调用本机 C# 后端，合并四个社区 hosts 源 + 内置 IP，用 Git 智能 HTTP 的 `info/refs` 下载速率排序，把前 3 个写入 `IPAddresses`（替换前自动备份）
- **最近建连可观测**：「查看GitHub建连状态」显示本次启动以来最近一次成功建连的 IP、来源（固定配置/自动选路/动态回退）和时间

## P1：非管理员运行明确告警

`app.manifest` 已声明 `requireAdministrator`，但 `start`/脚本/启动器直拉可绕过，此前后端在 WinDivert 失败时静默降级为 `127.0.0.1:38457` 正向代理、用户无感知。

- 启动时 `IsAdministrator()` 检测，非管理员弹窗「继续降级/退出」（默认退出）
- 托盘气泡二次提醒

## 验证结果（2026-11-20 实测）

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| `git ls-remote` | 21s 超时失败 | 1.28s 成功 |
| `info/refs` 首包 | 6.3s | 651ms / 328ms |
| `git-upload-pack`（小请求） | 24.9s 险超时 | 357ms |
| clone 结果 | 反复失败 | 连续 2 次成功（exit 0） |
| clone 耗时 | 失败 | 9.3s / 10s |
| 吞吐 | ~20 KB/s | ~6.4 MB/s（≈320 倍） |

编译：后端 `.NET 10`（6 个 warning 均为原有代码）、UI `net45`（0 警告 0 错误）。

## 下载与使用

- 下载 `fastgithub-win-x64.zip`，解压后以**管理员身份**运行 `FastGithub.UI.exe`（透明拦截依赖 WinDivert，非管理员会降级为正向代理）
- 首次使用需安装并信任 CA 证书（程序会自动导入）
- 用 `fastgithub-win-x64.sha256` 核对 `fastgithub.exe` 与 `FastGithub.UI.exe` 的哈希
- 详细改动说明见 [docs/fork-changes.md](https://github.com/FluxForceDynamics/FastGithubOps.UI/blob/main/docs/fork-changes.md)
