# FastGithubOps.UI v2.6.17

## 管理员启动与登录自启

- Windows 托盘程序要求管理员权限。手动启动时如果程序检测到权限不足，可以请求 Windows 以管理员身份重新打开。主窗口和托盘图标提示会显示管理员运行状态。
- 自启由 Windows 任务计划程序在指定管理员账户登录时以最高权限运行。托盘启动后核对实际权限，后端继承该权限。启用、迁移和关闭自启均在托盘「设置」中操作，「启动后最小化」可单独保存。
- 迁移时先核对计划任务的账户、路径和访问权限，再移除旧版注册表自启项。登录自启失败时，可通过任务计划程序的最近运行结果和 `logs/ui-error.log` 排查。

## 下载与升级

1. 下载 `fastgithub-win-x64.zip` 和 `fastgithub-win-x64.sha256`，将 ZIP 完整解压到同一目录。需要管理员自启时，请以管理员身份将完整程序解压到普通用户无法修改的目录，例如 `C:\Program Files\FastGithubOps.UI`。
2. 在解压目录运行 `Get-FileHash -Algorithm SHA256 -LiteralPath .\fastgithub.exe,.\FastGithub.UI.exe`，将两个哈希与清单逐项核对。
3. 使用要自动启动托盘的管理员账户打开 `FastGithub.UI.exe`，在托盘「设置」中点击「启用自启」。如果设置中识别出旧版自启项，点击「迁移旧版自启」。

首次设置和登录后的检查方法见 [Windows 登录自启](https://github.com/FluxForceDynamics/FastGithubOps.UI/blob/v2.6.17/README.md#windows-登录自启)。
